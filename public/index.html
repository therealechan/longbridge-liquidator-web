常见问题
1. 登录长桥开发者中心 open.longportapp.com
2. 在应用凭证页面获取 App Key、App Secret、Access Token
3. 确保账户已开通交易权限
详见：https://open.longportapp.com/
凭证仅保存在浏览器 localStorage，仅限本机访问。
服务器绑定 127.0.0.1，外部网络无法连接。
API 调用直接从本地发往长桥服务器，不经过任何第三方。
演示模式：使用模拟数据，无需凭证，适合体验界面。
实盘模式：连接真实 Longbridge API，查看持仓并执行市价卖出。
使用实盘模式需先启动本地服务器（npm start 或 npm run dev）。
支持美股 (.US)、港股 (.HK)、新加坡 (.SG)。
清仓使用市价单 (Market Order)，按当前市价立即成交。
部分失败时，成功的订单正常处理，失败的显示错误信息。
